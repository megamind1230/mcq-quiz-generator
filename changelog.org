#+TITLE: changelog.org
#+DESCRIPTION: Update tracking for MCQ Quiz Generator

Inspired by [[https://github.com/megamind1230/nextlearn][megamind1230/nextlearn]] MCQ feature.

* v0.6.0 - 2026-09-11
  Three quiz modes + refactoring & deduplication.
  - [X] *Three quiz modes:* Loop (instant feedback + retake wrong answers),
        Instant (instant feedback, no retake), Classic (deferred feedback, results page)
  - [X] *Removed instantFeedback setting* — feedback now determined by mode choice
  - [X] *Answer locking* in Loop/Instant modes (anti-cheat: can't change answers after selection)
  - [X] *Refactoring:* extracted =format.ts= (shared =formatTime= + =escapeHtml=)
  - [X] *Refactoring:* extracted =constants.ts= (=ANSWER_LABELS= + =ANSWER_KEYS=)
  - [X] *Refactoring:* deduped =exactMatch= — quizExporter imports from quizModes
  - [X] *Refactoring:* extracted =leaveQuiz= cleanup function (4 call sites consolidated)
  - [X] *Refactoring:* extracted =prepareQuestions= pure function from startQuiz
  - [X] *Refactoring:* added =MODE_CONFIG= for mode picker (config-driven, not hardcoded)
  - [X] *Refactoring:* moved inline styles to CSS classes in results view
  - [X] *CSS:* added =.tag-instant= class, =.results-*= classes, =.export-*= classes
  - [X] Tests: 45 tests across 7 files, all green; typecheck clean

* v0.5.0 - 2026-09-08
  Loop mode, bulk encrypt, settings expansion, quality-of-life.
  - [X] *Loop mode:* retakes wrong answers in batches of 15 until all mastered;
        instant feedback forced on; no results page; mode picker overlay after
        selecting a quiz (Loop vs Normal, always asks fresh)
  - [X] *Mode picker overlay* -- Choose Loop or Normal mode before each quiz
  - [X] *Bulk encrypt:* Generate tab has "Bulk Encrypt .mcq -> .emcq" button
        that encrypts all unencrypted =.mcq= files in the output directory
  - [X] *Settings expansion:* added Randomize Options, Randomize Question Order,
        Encrypt Output toggles; instant feedback hint ("Always on in Loop Mode")
  - [X] *Remember last file picker directory* -- file dialog opens where you left off
  - [X] *AI prompt keyword constraint:* prompt template now tells the AI not to
        translate =## Question=, =**[Answer: ...]**=, =**Explanation:**=, =A.=, =B.=, =C.=, =D.=
  - [X] Extracted =quizModes.ts= (grading + loop logic) with unit tests (45 total)
  - [X] Renamed =plan-todos.org= -> =plans-and-todos.org=
  - [X] README.org updated: rich .mcq examples (LaTeX, code), new features documented

* v0.4.0 - 2026-08-31
  Multi-answer questions + security + companion mobile PWA.
  - [X] Multi-answer support: =.mcq= files can now have several correct options
  - [X] New (breaking) multi-answer syntax: =**[Answer:A,C]=** -- comma-separated
        letters, *no space* after the colon (single stays =**[Answer: B]=**)
  - [X] =McqQuestion= gained =correctIndices: number[]= and =multiAnswer=;
        grading is exact-match set equality (all-or-nothing)
  - [X] Generator supports multi-answer mode (=buildPrompt=, =generateMcqs=)
        with select-all prompts
  - [X] Quiz UI: checkbox markers for multi, radio for single; "Single answer"
        / "Select all that apply" tags; results show Your/Correct Answer(s)
  - [X] Optional AES-256-GCM encrypted output (=.emcq=) with app-embedded key;
        app opens both =.mcq= and =.emcq= seamlessly
  - [X] Leave button in quiz header (red, =← Leave=, confirm dialog)
  - [X] Tabs styled with amber active underline (=--amber= var)
  - [X] Tests rewritten/extended -- now 38 tests across 6 files
  - [X] Repository renamed =mcq-quiz-generator= -> =mcq-quiz-generator-desktop=
  - [X] New companion project =mcq-quiz-generator-mobile=: offline student PWA
        that imports, decrypts, and grades =.mcq=/=.emcq= files (no generation)
